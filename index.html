Writing LaTeX yourself, and what gets lost

To add LaTeX Leh? Tex has no button for, insert a Raw LaTeX block (More → Raw LaTeX): it is copied into this file exactly as you type it. Changes typed here are not possible because this view is rebuilt from the document each time.

Opening a .tex file converts it into Leh? Tex blocks. Anything Leh? Tex can't show as a block is kept as a Raw LaTeX block and listed in the import report, but layout details (spacing tweaks, custom macros used inline, some table features) can be simplified. Keep your original .tex if you need it unchanged.
