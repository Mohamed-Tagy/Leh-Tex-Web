A closed beta

Leh? Tex is invite only for now. When it first starts, it asks for your personal invite key and shows the Beta Terms of Use. Without a key it doesn’t open.

Installing

  1. Open the file you downloaded.
  2. Windows may say it protected your PC, because the installer isn’t code-signed yet. Choose More info, then Run anyway.
  3. Type your invite key and accept the Beta Terms.

Already using Leh? Tex? It updates itself: use Check for updates in About, or press Ctrl+K. Version 1.1.0-beta.1 can’t update itself, so install this one once.

What’s new

  • Home is now the start screen. The Home button and the Leh? Tex logo save your document, close it and take you to Home, where you choose what to do next. To go back to a document, click it in the list.
  • Your work comes first on Home: "Pick up where you left off" is right under the greeting, then your own templates, then the built-in ones.
  • A download page: https://mohamed-tagy.github.io/Leh-Tex-Web/download/ always has the newest version.
  • The web app is up to date again: https://mohamed-tagy.github.io/Leh-Tex-Web/

If you have 1.1.0-beta.1, install this version by hand once. After that, new versions arrive through Check for updates.
